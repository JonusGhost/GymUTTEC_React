# Styles Directory

This directory contains global styles and theme configurations for the application.

## Structure

- `global.css`: Application-wide styles and CSS reset
- `theme.js`: Theme configuration (colors, typography, spacing)
- `variables.css`: CSS variables for consistent styling
- `components/`: Component-specific styles

Guidelines:
- Use CSS modules for component-specific styles
- Follow BEM naming convention
- Maintain consistent color schemes and spacing
- Keep styles modular and reusable
