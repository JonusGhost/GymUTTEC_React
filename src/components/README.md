# Components Directory

This directory contains reusable React components organized by their purpose and scope.

## Structure

- `/common`: Shared components used across multiple features (buttons, inputs, cards)
- `/layout`: Components that define the application's layout (header, footer, navigation)
- `/features`: Feature-specific components organized by domain

Guidelines:
- Keep components focused and single-purpose
- Use consistent naming conventions
- Include prop-types or TypeScript interfaces
- Document component usage and props
